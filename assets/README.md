# NearChess logo

The logo is an original SVG made for NearChess: a mint rook on graphite with an `N` cut-line. The mark is deliberately geometric so it remains readable as an Android launcher icon, toolbar icon and monochrome mark.

Palette:

- Graphite: `#121A1C`
- Mint: `#71D8BC`
- On-surface: `#EDF3EF`

Do not replace it with Chess.com artwork or a copied chess-piece set.
